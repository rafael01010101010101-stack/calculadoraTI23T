# Calculadora em C# (Console Application) 🧮

Este repositório contém o meu **primeiro projeto prático desenvolvido em C# utilizando a interface de terminal (Console)**. Ele foi criado como parte das minhas atividades práticas na turma TI23T.

O objetivo principal deste projeto foi aplicar os fundamentos iniciais de lógica de programação orientada a objetos e entender a sintaxe da linguagem C# dentro do ecossistema .NET.

---

## 🚀 Recursos do Projeto
- **Operações Matemáticas:** Execução de cálculos básicos (Soma, Subtração, Multiplicação e Divisão).
- **Interface via Terminal:** Interação direta com o usuário através de comandos inseridos na tela de console.
- **Tratamento de Dados:** Validação simples de entradas para evitar erros de execução (como divisão por zero).

## 🛠️ Tecnologias Utilizadas
- **Linguagem:** C#
- **Plataforma:** .NET
- **Ambiente de Desenvolvimento:** Microsoft Visual Studio (arquivos `.sln` inclusos)

---

## 📈 Aprendizados Adquiridos
Sendo o meu primeiro contato de desenvolvimento com C#, este projeto foi fundamental para consolidar conceitos como:
1. Entrada e saída de dados no terminal (`Console.ReadLine` e `Console.WriteLine`).
2. Estruturas condicionais (if/else ou switch/case) para o menu de opções.
3. Conversão e manipulação de tipos de variáveis (parsing de strings para números).
